# Картинки титанов

Сюда кладутся изображения для раздела «Тренировки». Сами картинки в git не попадают (см. `.gitignore`) — в репозитории остаётся только этот файл.

## Имена файлов

Базовая картинка титана — приложение само перекрасит её под текущий материал:

- `strength.jpg` — Сила (Рагнар)
- `agility.jpg` — Ловкость (Зоро)
- `endurance.jpg` — Выносливость (Спартак)
- `burst.jpg` — Взрывная выносливость (Тодзи)
- `flexibility.jpg` — Растяжка (Алукард)

Отдельная картинка для стадии (другая стойка, другая броня) — показывается как есть, без перекраски:

- `<титан>-wood.jpg`, `-bronze.jpg`, `-silver.jpg`, `-gold.jpg`, `-jade.jpg`

Например, `agility-gold.jpg` — Зоро на золотой стадии.

Подходят `.jpg`, `.png` и `.webp`. Лучше всего смотрятся вертикальные картинки 3:4 на тёмном фоне.
